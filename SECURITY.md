# Security reporting

QuantumPocket is the public wallet name; Quantum Seal remains the technical protocol
and repository name. Current downloadable builds are devnet previews. No independent
security audit has been completed and no mainnet program is pinned in this release.

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/qcommit/quantum-seal-extension/security/advisories/new).
Use [GitHub issues](https://github.com/qcommit/quantum-seal-extension/issues) for general
installation problems. Never attach wallet keys, passphrases or backup files. There
is no promised response SLA or paid bug bounty.

See [the core security policy](https://github.com/qcommit/quantum-seal-wallet/blob/main/SECURITY.md)
and the extension’s [local review](docs/SECURITY-REVIEW.md) for the current model and limits.
